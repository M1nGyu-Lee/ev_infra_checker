# Streamlit 대시보드 구성 및 실행

## 실행

```powershell
pip install -r requirements-app.txt
python -m streamlit run streamlit_app.py
```

## 발표 우선순위별 네비게이션

| 순위 | 대상 | 탭 | 한 화면 메시지 |
|---|---|---|---|
| 1순위 | 정책 결정 | **발표·정책 브리핑** | 결론 → 정의 → YTD 괴리 → 지역 점검 후보 → 주의 |
| 탐색 | 정책·실무 | 지도 · 급속 추이 · 지역 상세 | 필터로 상대 부담·피크 깊게 보기 |
| 2순위 | 사업자 | 설치 힌트 사분면 · 차지인포 · 활성기 · 한전 | 권역별 급·완속 보급 강도 힌트 (설치 확정 아님) |
| 3순위 | 기초 | EV·충전소 총량 | 전국 규모·기간 상태 팩트 |
| 참고 | 담당자 | 데이터 안내 | 파일·방법론·한계 |

기본 진입: **1순위 · 발표·정책 브리핑** (`pages/00_발표_브리핑.py`)

## 화면 계층

| 페이지 | 표시 | 주 데이터 |
|---|---|---|
| 발표·정책 브리핑 | 스토리보드(`st.metric` · `line_chart` · `bar_chart`) | YTD · national monthly · master 2024 |
| 시·도 지도 | 해석 가이드 + GeoJSON + 순위 | `sido_year_master.csv` |
| 급속 이용 추이 | 전국 EV↔kWh 스토리 + 시·도 추이 | `charge_sido_monthly_panel.csv` |
| 지역 상세 | KPI + 피크 힌트 | 월·연 분석 테이블 |
| 급·완속 설치 판단 | 사분면 → 보급률/누적 → 활성기 → 한전 | 차지인포 processed + master |
| EV·충전소 총량 | 전국 KPI + 기간 상태 | master, EV monthly, chargeinfo annual |
| 데이터 안내 | 메타·forecast 문서 | forecast/ |

## 인터랙션

- 발표 브리핑은 필터를 최소화하고 스토리 순서로 고정
- 탐색 화면: 상단 네비 · 사이드바 기준연도·지역
- 부분연도(2025)·설비 stale(2023+) 배지 유지

## 지도 해석

- EV천대당 활성기: 낮을수록 공급 여력 빠듯한 방향
- 활성기당·충전량·EV: 높을수록 이용·수요 부담 방향
- 2023년 이후 설치 재고는 지도에서 제외
