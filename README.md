# EV Infra Checker

**전기차 증가세에 충전 인프라는 따라가고 있을까?**  
공공 급속 충전기를 중심으로, 전국 17개 시·도의 **이용 부담**과 **충전 여력**을 비교하고 **공공급속 배치 방향**을 제시하는 Streamlit 대시보드입니다.

- GitHub: https://github.com/M1nGyu-Lee/ev_infra_checker  
- 발표 덱(원본): `Charger_Infra_Checker_Briefing_live.pptx` (25장)  
- 앱 기본 진입: **발표·정책 브리핑**

## 1. Overview

| 항목 | 내용 |
|---|---|
| 프로젝트 | EV Infra Checker (Charger Infra Checker 배포본) |
| 핵심 질문 | 전기차 수요 대비 공공급속 이용·여력이 어긋날 때, **어디에 공공급속 배치를 우선할 것인가?** |
| 분석 범위 | 전국 **17개 시·도**, 공공 **급속** 중심 |
| 산출물 | Streamlit multipage 대시보드 + 발표 브리핑 스토리 |
| 청중 | 환경부 예산·배치 방향을 보는 의사결정자 |

한 문장 요약:  
전기차 등록은 늘었는데 공공급속 **실제 가동·충전량**은 같은 속도로 늘지 않는다. 이용 부담(가동 1기당 kWh)과 충전 여력(EV 1,000대당 실제 이용 충전기)이 함께 나쁜 곳에 **공공급속 배치를 우선하는 것이 바람직하다.**

## 2. 주제 · 목표 · 예상 결과

### 주제

- EV 등록 증가와 공공급속 **실제 사용**(가동 대수·충전량) 추이 비교
- **실제 가동 1기당 충전량**(이용 부담)으로 시·도별 바쁨 정도 파악
- **전기차 1,000대당 실제 이용된 충전기 수**(충전 여력)로 상대 부족 파악
- 두 지표를 겹쳐 **배치 우선 시·도**를 제시

설문(환경공단·EV트렌드코리아 등)은 **배경**입니다. 결론 KPI는 **국토부 EV · 환경부 공공급속**입니다.

### 목표

1. 같은 기간(2024·2025 각 1–8월)으로 EV·실제 가동·충전량의 속도 차이를 확인한다.
2. 2024년 기준 이용 부담·충전 여력으로 17시·도를 비교한다.
3. “어디에 배치를 우선하는 것이 바람직한가”에 데이터로 답한다.  
   → **배치 방향**이지, 확충 % 처방·설치 확정이 아니다.

### 예상 결과 (효과)

- 양·질 측면에서 **전국 공공급속 우선배치 후보**를 좁힐 수 있다.
- 이용 부담만 큰 곳과 여력만 부족한 곳을 **한 처방으로 묶지 않고** 구분해 볼 수 있다.
- 발표 숫자를 대시보드에서 **같은 정의로 재현**할 수 있다.

## 3. 주요 분석 결과

발표 덱·브리핑과 동일한 핵심 숫자입니다. (동기간: **2024 vs 2025 · 각 1–8월**)

| 지표 | 변화 | 값 |
|---|---|---|
| 전기차 등록 | **+27.5%** | 586,880대 → 748,077대 |
| 실제 사용된 충전기 | **+4.2%** | 8,118기 → 8,463기 |
| 공공급속 충전량 | **+4.0%** | 96.0 → 99.9 GWh |

**선결론:** 차는 늘었는데, 실제 가동·충전량은 따라가지 못한다.

| 관점 | 정의 | 우선 시·도 (2024) |
|---|---|---|
| 이용 부담 | 실제 가동 **1기당 kWh** (전국 평균 17,353) | 서울 · 인천 · 제주 · 부산 · 대전 |
| 충전 여력 | EV **1,000대당** 실제 이용 충전기 (전국 평균 12.4기, 낮을수록 부족) | 부산 · 서울 · 인천 · 대구 · 제주 |
| 종합 | 둘 다 부족 | **서울 · 인천 · 부산 · 제주**부터 배치 우선이 바람직 |
| 구분 | 부담만 / 여력만 | 대전(부담) · 대구(여력) — 이유가 다름 |

## 4. 이 패키지로 할 수 있는 일

이 리포는 분석 결과물을 **바로 열어보는 Serving 패키지**입니다.

| 기능 | 결과 |
|---|---|
| 발표 브리핑 | PPT와 같은 스토리(전년 대비 → 종합)를 인터랙티브로 확인 |
| 시·도 필터 | 전국/개별 시·도로 EV·가동·충전량 괴리 재확인 |
| 지도·순위 | 이용 부담·충전 여력 choropleth 및 17시·도 순위 |
| 추이·지역 상세 | 월별 시계열, 피크·KPI 드릴다운 |
| 급·완속 설치 판단 | 급·완속 구축 비중·보급 강도 **참고 힌트** (결론 KPI 아님) |
| 데이터 안내 | 지표 정의·기간·한계 문서화 |

## 5. 대시보드 구성

| 순위 | 페이지 | 역할 |
|---|---|---|
| 1 | **발표·정책 브리핑** | 본편. 전년 대비 · 종합(둘 다 / 부담만 / 여력만) |
| 탐색 | 시·도 지도 | 부담·여력 지도 + 순위 |
| 탐색 | 급속 이용 추이 | 전국·시·도 월별 추이 |
| 탐색 | 지역 상세 | 시·도 KPI · 피크 |
| 참고 | 급·완속 설치 판단 | 구축 구조 배경 |
| 참고 | EV·충전소 총량 | 전국 규모 맥락 |
| 참고 | 데이터 안내 | 방법론·한계 |

발표 시연 권장 경로: **발표 브리핑 → 전년 대비(전국) → 종합(2024)**.  
시연에서 들어가지 않는 메뉴: 급완속 설치 판단 등 사이드바 기타 페이지.

## 6. 데이터 소스

| 역할 | 출처 | 설명 |
|---|---|---|
| 수요 | 국토부 통계누리 · 연료별 자동차등록현황 | 2019-01~ · 월 · 전기만 · 17시·도 |
| 이용 (결론 KPI) | 환경부 공공급속 연월별 충전량·횟수·시간 | 기기×연월 원장 ~2025-08 |
| 공급 배경 | 환경부 급·완속 충전기 현황 API | 시·도 코드 조회 → CSV |
| 교차확인 | 한국전력 지역별 전기차 현황 | 국토부 EV 교차 |

용어:

| 쓸 말 | 정의 |
|---|---|
| 실제 가동 충전기 | 해당 기간 충전 기록이 있는 환경부 공공급속 |
| 이용 부담 | 실제 가동 1기당 충전량(kWh) |
| 충전 여력 | 전기차 1,000대당 실제 이용된 충전기 수 |
| 배치 우선 | 먼저 두는 **방향**. 설치 확정 아님 |

## 11. Usage

1. 앱 실행 후 왼쪽에서 **발표·정책 브리핑**을 연다.
2. **전년 대비**: 시·도=전국, 연도=2025년 1–8월(전년 같은 달 비교)로 EV·실제 가동·충전량 괴리를 본다.
3. **종합**: 연도=2024로 전환해  
   - 둘 다 부족(서울·인천·부산·제주)  
   - 이용 부담만(대전)  
   - 충전 여력만(대구)  
   을 확인한다.
4. 필요 시 지도·추이·지역 상세에서 같은 지표를 깊게 본다.

## 12. 한계 · 해석 주의

- 시·도 단위 집계입니다. 구·군·동은 원천에 없어 보지 않았습니다.
- 이용 부담은 **1기가 넣은 전기량**이지 대기열·체감이 아닙니다. 안 쓰인 기는 숫자에 안 들어갑니다.
- 2025년은 **1–8월**이라 같은 달끼리만 비교합니다.
- 설문·언론은 배경이며 결론 KPI가 아닙니다.
- 쓰지 않는 주장: 확충 % 처방, “이미 설치 확정”, 급·완속 총량만으로 공공급속 충분/부족 단정.
