# EV Infra Checker

전기차 증가에 **공공급속 인프라**는 따라가는가?  
국토부 EV · 환경부 공공급속 이용 · 환경부 급·완속 현황 API를 한 화면에서 비교하는 Streamlit 대시보드입니다.

> 핵심 질문: 수요 대비 공공급속 이용·여력이 어긋날 때, **어디에 공공급속 배치를 우선할 것인가?**

---

## 1. 주제

전국 17개 시·도를 대상으로, 전기차 등록(수요)과 공공급속 실제 이용(부담)·급·완속 구축 구조(공급)를 **같은 정의로 분리·비교**합니다.

“충전기가 이미 많다”는 총량 통계와 “충전이 불편하다”는 체감이 동시에 나타나는 이유는, 자료의 **모집단·지표 정의**가 다르기 때문입니다. 이 프로젝트는 총량으로 충분·부족을 단정하지 않고, 세 계층을 나눠 상대 부담을 봅니다.

| 계층 | 자료 | 역할 |
|---|---|---|
| 수요 | 국토교통부 자동차등록현황 | 시·도별 EV 등록·증가 |
| 이용 | 환경부 공공급속 연·월 충전량 | 충전량(kWh)·**실제 가동 충전기(활성기)** |
| 공급 구조 | 환경부 급·완속 충전기 현황 API → CSV | 급·완속 구축·**급속 비중** (시·도 코드 조회) |

---

## 2. 목표

1. EV 증가와 공공급속 활성·이용 속도의 **어긋남**을 시·도·연도·동기간으로 확인한다.
2. **활성기당 충전량**, **EV 1,000대당 활성 급속기**, **급속 비중(완속 제외)** 으로 상대 부담·여력을 본다.
3. 이용은 많은데 급속 여력·비중이 상대적으로 낮은 지역을 **우선 점검 후보**로 제시한다.  
   → 공식 부족 판정·확충 % 처방·“이미 설치 확정”이 아님. 배치 우선 방향만 제시.
4. 전처리된 분석 테이블 + Streamlit으로 **재현 가능한 참고 자료**를 제공한다.

의사결정 스토리:

1. **늘려야 하나** — EV 증가가 공공급속 활성·이용을 앞서는가  
2. **어디에 먼저** — 이용 부담이 크고 급속 여력·비중이 낮은 시·도/권역  
3. **종합** — 세 계층을 묶어 우선 점검 후보 제시

---

## 3. 예상 결과 (이 리포로 도출 가능한 것)

| 결과물 | 내용 |
|---|---|
| 전국 신호 | EV 등록 vs 공공급속 충전량·활성기 추이, 동기간(YTD) 증가율 비교 |
| 시·도 지도·순위 | 이용 부담(활성기당 kWh), 총 충전량, EV천대당 활성기 choropleth·막대 |
| 지역 상세 | 시·도 KPI, 피크월·평균 초과율, 월별 패널 |
| 설치 힌트 | 급속 비중·보급 강도 사분면 (설치 확정 아님, 배치 우선 힌트) |
| 총량 맥락 | 전국 EV·급·완속 구축 규모 스냅샷 |
| 해석 가이드 | 지표 정의·데이터 한계·관측/추정 구분 (`데이터 안내`) |

**하지 않는 것:** 미래 부족 단정, 확충 목표 %, 설문·언론을 결론 KPI로 사용.

## 4. 이 패키지가 하는 일

이 리포는 **분석 파이프라인의 Serving(대시보드) 배포본**입니다.

```text
국토부 EV / 환경부 공공급속 / 환경부 급·완속 API(CSV)
        ↓  (원본 저장소에서 전처리·분석 테이블 생성)
data/analysis · data/processed · GeoJSON
        ↓
Streamlit multipage app  (이 리포)
        ↓
발표 브리핑 · 지도 · 추이 · 지역 · 설치 힌트 · 총량 · 데이터 안내
```

| 할 수 있는 일 | 설명 |
|---|---|
| 정책 브리핑 | 결론 → 전국 신호 → 지역 후보 순으로 스토리 읽기 |
| 탐색 | 연도·지표·시·도 필터로 지도·시계열·지역 KPI 재확인 |
| 사업자 힌트 | 급·완속 비중·보급 강도 사분면으로 배치 우선 방향 참고 |
| 로컬/Cloud 실행 | `streamlit run streamlit_app.py` 또는 Streamlit Cloud |

칼럼명은 **한글**(공유·열람용). 원본 분석 저장소의 영문 스키마와는 별도입니다.

## 9. 해석 시 주의

- 지도·순위는 **상대 비교**이며 공식 부족·포화 판정이 아닙니다.
- **활성기** = 해당 기간 충전 실적이 있는 **실제 가동 충전기**.
- 공공급속 이용 실적과 급·완속 구축 현황은 **같은 ‘충전기’가 아닙니다**.
- 2025년 공공급속 충전량은 **부분연도(관측월)** 일 수 있습니다.
- 설비 설치연도 재고는 갱신 단절이 있어, 최신 판단은 **활성기**를 우선합니다.
- 결론 KPI는 **국토부 · 환경부 공공급속 · 환경부 급·완속 현황**. 설문·언론은 배경입니다.
