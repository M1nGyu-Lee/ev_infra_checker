## 3. 추이 분석 (보완 전)

### 3.1 환경부–한전 교정 구간 (2020-01~2020-06)

- 시·도별 `ratio = 한전 급속 kWh ÷ 환경부 공공급속 kWh` 월별 비율 산출
- 시·도 중앙값 + 전국 중앙값 **풀링** (표준편차 0.2 초과 시 전국 쪽 축소)
- 비율 클리핑: 0.3 ~ 5.0

### 3.2 보조 부하 지수 (전국)

- 시간대별 부하 파일의 급속 행: 일별 kW 합 → 월별 `load_kw_sum`
- 동월 지수: `load_index(t) = load_kw_sum(t) / load_kw_sum(2020-동월)`
- 2020 동월 부하·관측이 없으면 2020년 월평균 부하 대비로 대체

### 3.3 충전소 현황 배분 (시·도)

- `share(sido, year) = 시도 충전소 수 / 전국 충전소 수`
- 연도별 스냅샷(한전 지역별 충전소 현황) 사용

## 4. 보완 모형과 가중치

### 구성요소 A — 환경부 연계 (MOE-scaled)

```
A(sido, t) = MOE_charge(sido, t) × ratio(sido)
```

### 구성요소 B — 부하·충전소 배분 (Load-share)

```
B(sido, t) = National_anchor(month) × load_index(t) × share(sido, year)
National_anchor(month) = Σ 한전 관측(2020-동월)
```

### 최종 혼합

```
KEPCO_est = w_moe × A + w_load × B
```

- **w_moe (환경부 연계):** 100%
- **w_load (부하·충전소 배분):** 0%
- **가중치 산출:** 2020년 1~6월 관측에 대해 Leave-One-Month-Out, 전국 WAPE 최소화 (0~100% 그리드 탐색)

## 6. 한계 (반드시 읽기)

- 한전 충전량 원본은 Excel 104만 행 제한으로 **2020년 6월 말까지만** 신뢰 관측
- 환경부는 공공급속망, 한전은 **전체 망**이라 모집단이 다름 → 비율은 교정값이지 실측 비율 아님
- 시간대별 부하는 kW 부하 합이며 kWh 실측이 아님 → **지수**로만 사용
- 추정 구간은 환경부·보조 데이터 추이를 반영한 **보완값**이며 실제 한전 실적 아님
