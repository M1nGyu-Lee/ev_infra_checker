## 4. 추이 분석 (예측 전 수행)

### 4.1 동기간 성장률 (YTD)

- **비교 구간:** 2025년 1–8월 vs 2024년 1–8월
- **산출:** 시·도별 월별 YoY 비율의 **중앙값** → `robust_growth_factor`
- **극단값 제한:** 0.85–1.25
- **전국 중앙 성장률:** 1.0426 (4.26%)

### 4.2 계절성 (Sep–Dec)

- **참조:** 2024년 9–12월 동월 관측값 (전년 동월)
- **학습 시작:** 2019-01 (2017년은 5개월만 있어 계절 학습 제외)

### 4.3 지역 풀링

- 시·도 YTD 성장률 표본의 표준편차가 0.15 초과 시, 지역 성장률을 전국 중앙 성장률 쪽으로 **부분 축소**

## 5. 예측 모형과 가중치

### 모형 A: 계절 기준 (Seasonal Naive)

```
forecast(t) = observed(t - 12개월)
```

### 모형 B: 계절 성장률 (Seasonal Growth) — 기본 후보

```
forecast(t) = observed(t - 12개월) × robust_growth_factor
```

### 최종 채택

- **선택 모형:** `seasonal_naive`
- **가중치:** 계절 성장률 0%, 계절 기준 100%
- **선택 규칙:** 2023·2024년 백테스트(8월까지 학습 → 9–12월 검증) WAPE가 더 낮은 모형을 100% 채택 (혼합 가중치는 검증 우열에 따라 1.0/0.0)
